# AI 账号 · 母题定位与四层结构（选题池 v3）

> 2026-08-26 会话沉淀。解决核心痛点：历史内容（选型连载）与未来内容（热点快讯）的延续性问题。
> 前置文档：`连载口播稿经验总结-全系列总沉淀.md`、`ai-v2-16a84a08`（选题池 v2）、主文档 `86ea2943`（创作硬标准）。
> 核心结论：**公式缺的不是"判断"，是"落点"**——热点→翻译→判断→**落回母题**。

## 一、母题定位（账号为什么存在，一句话）

> **"一线 AI 落地实践者——帮你选对 AI、用对 AI、避开 AI 的坑。"**

证据：历史内容共同内核（系列①选哪个 / 系列②什么时候选换 / token 怎么省 / 多模态能力边界 / 纯科普数据底座）全部落在这句话上。数据底座（科普翻译型收藏健康）是**母题**带来的，不是追热点带来的。

观众心智目标："这账号 = 一家 AI 时代的餐厅，所有 AI 话题都在这个世界里讲：深挖选型，热点来了翻译成店里的事，还会自己给店里添新物件（开源作品）。"

## 二点五、世界观全量迁移机制（2026-08-26 过路定调）

**世界观（餐厅）+ 配方（比喻映射）= 一套完整语言，全量迁移到所有内容，不设限。**

不是"只有选型内容用餐厅"，而是**每个选题进来，第一步就是配配方**："这期在餐厅世界里是什么？"——配好配方再写稿。配方表随内容扩展，不是固定死的一组映射。

已配配方（示例，随选题持续扩充）：

| 选题 | 餐厅配方 |
|---|---|
| Harness 5 插件 | 后厨家什：一把好刀、一口好锅、一个记事本（插件=厨具/工具） |
| 企微 MCP | 后厨新接的送菜通道，插上就能下单（MCP=供应链接口） |
| 豆包办公实测 | 隔壁新开的"预制菜+机器人"餐厅，先替你去尝尝（豆包=新店） |
| Agent 溃败 | 请了个很能干的帮厨，换个厨房他就死机（Agent=帮厨，环境=厨房） |
| CPA 全科 | AI 把注会证考下来了——但账房的活，是背题还是算账（CPA=账房考试） |
| 钉钉 ONE 死因 | 一家店上了套收银系统，结果把自己干倒闭（企业 AI=收银系统） |
| MoE 番外 | 100 个厨师只叫醒 2 个上灶——人力成本就这么省下来的（MoE=叫醒机制） |
| 蒸馏 | 偷师算不算手艺？把大师的菜拆了重做（蒸馏=偷师拆解） |
| Anthropic 放缓 | 卖菜的批发生意做到头了，大家排队去开餐厅（API=批发，应用=开店） |
| 特斯拉接豆包 | 给流动餐车装上新灶头（车机=餐车） |
| 毛选金句卡 | 店里的老主顾签筒：心里想个事，摇一签（作品=店里的物件） |

**唯一纪律（不是设限，是防翻车）**：配方可以自由配，但**每个配方必须对准真实机制**（本质依据表纪律不变）——比如 MCP 是协议不是实体，"送菜通道"别讲成"外卖平台"。配方配错料，懂行的一眼穿。

## 三、选题池 v3（带母题落点列）

### 主线
- 系列③《怎么从加盟店开成自己的店》——换骨架别再三段式，继续排。

### 主线衍生（Harness 深潜）
- **Harness 最核心 5 个插件** ✅
  - 判断句：插件不是越多越好——是这 5 个，改变了我每天怎么干活。
  - 结构：按"解决什么问题"排（记忆/文件/编排/读图/语音…），每个带一句"什么时候用它"，收尾落母题：对应的是真干活，不是参数。
  - 风险：技术门槛高，须术语双轨——配方=后厨家什（插件=给后厨添的趁手工具），见二点五配方表。

### 支线快讯（翻译落回母题）
| 选题 | 母题落点 | 判定 |
|---|---|---|
| 企微 MCP（亲历版） | MCP 是 AI 的 USB，怎么接进你的工作流——亲历避坑 | ✅ S 强 |

### 品牌资产（开源作品）
- **毛选金句卡开源** ⚠️ 分两条线：
  - 作品线（开源）：做。官网使命"展示自研好玩的东西"同源，信任资产。开源=GitHub 仓库 + README + LICENSE + 代码整理（能跑/能用/别人能看懂）。
  - 内容线（口播）：必须翻译成 AI 落地实践——"我用 AI 做了个答案之书：从 0 到 1 的玩具项目，怎么定交互、怎么让 AI 释文、怎么让人'把自己套进去'"。判断句：AI 玩具有没有人用，不看功能多，看能不能让人对号入座——戳中感才是产品。
  - ⚠️ 红线（赶工不可跳过）：①"摇签/答案之书"有迷信擦边风险（违禁词清单：迷信不碰），平台口径先测；②毛选属政治文本，文案口径必须中性（原文引用+白话解读，不加立场演绎）。
